# RUIBU · 把零散的资料变成能复习的笔记

截图在相册里，公式在 PDF 里，AI 的解释留在聊天窗口里。等到复习或写报告时，往往得把这些东西重新找一遍。RUIBU 把图文笔记、思维导图、AI 问答和待办放在一起，让你从记录一个疑问到整理思路，再到安排下一次复习，都能在同一个地方完成。

**记下材料 → 问清疑点 → 摘录答案 → 用画布梳理关系。**

[下载 Android APK 和 Windows 版](https://github.com/Yexingmaniqong/ruibu/releases/latest)

## 从一条高数笔记开始

1. **记录题目和卡住的地方。** 把讲义截图拖进笔记，直接在图片前后写推导。正文和独立网格使用同样大的方形缩略图，网格一行四张，点开可看原图。正文支持 LaTeX 公式和标签。
2. **只留下 AI 回答里真正有用的部分。** 配置 DeepSeek 后，在「AI 问答」里追问某一步。选中解释中的关键段落，点「加到笔记」，就能写入指定笔记。整条回答也能保存。
3. **把线性的记录展开成思维导图。** 从笔记打开画布，把定义、例题和易错点摆到不同位置，再用箭头连起来。「关系画布」还能把多条笔记放在同一张图里，方便串联章节或整理一个项目。画布可导出为兼容 Obsidian 的 `.canvas`。
4. **把下一步排进待办。** 给「重做第三题」设个时间，到了手机会提醒。暂时没定时间的事可以直接记下来，做完后勾选归档。

这套流程也适合读书摘录、研究资料、会议记录和项目复盘。日记可按日期整理，需要跨主题回看时可以用标签和搜索。

## 安装

| 平台 | 使用方法 |
| --- | --- |
| Android | 在 GitHub Releases 下载 `RUIBU-版本号.apk`，打开安装。此版要求 Android 7.0 或以上。 |
| Windows 64 位 | 下载 `RUIBU-版本号-win64.zip`，完整解压后打开 `RUIBU.exe`。也可以运行包里的「安装到本机.cmd」创建快捷方式。 |

## 常用操作

- **笔记和图片**。在编辑器里输入文字，底栏可选相册或拍照。手机长按、电脑按住图片后拖动。网格内会实时腾出位置，正文用短标记显示插入点，拖到底部删除区松手可删除。只有图片的笔记可以从图组下方点「继续写文字…」。
- **标签**。点底栏 `#` 选择已有标签，或选「输入新标签」。输入 `#标签名` 后按空格即可生成标签块。
- **思维导图**。在普通笔记里点「创建画布」，添加文字、图片和连线。手机打开画布后先轻点一下即可操作。
- **AI 问答**。在「设置 → AI（DeepSeek）」保存自己的 API Key，测试连接后开始提问。图片是否可发送取决于所用模型。
- **待办与提醒**。点「待办 → 新建待办」，填写内容和可选的提醒时间。可随时改时间、清空提醒、标为完成或删除。
- **备份和迁移**。在「设置 → 数据」导出或导入 JSON。应用也支持导入 flomo 导出文件。

## Android 待办提醒

在待办页按提示开启通知。开启系统的「闹钟和提醒」权限可请求准时调度，未开启时系统可能延后提醒。到点后由 Android 发送「待办提醒」通知，横幅与震动受通知类别、勿扰及设备设置影响。点通知会进入待办页，应用在后台时也能收到。Windows 版需要保持 RUIBU 运行。

## 离线与数据

核心笔记、日记、画布和待办可离线使用。数据保存在当前设备，换设备可用 JSON 备份迁移。启用 AI 后，提交的问题和附带内容会发送给配置的 DeepSeek 接口，AI 问答需要联网。应用基于 MIT 许可证发布。
