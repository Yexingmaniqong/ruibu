# RUIBU

> 一条笔记里可以图文自由穿插，能展开成思维导图，也是日记本。纯本地、离线可用。

一套代码，四种形态：**网页** · **PWA** · **Android APK** · **Windows 桌面版**。
不需要账号，没有云端，数据只在你自己的设备里。

---

## 特性

| | |
|---|---|
| **图文混排** | 图片可以夹在文字的任意位置，也可以单独成块（一行四个的网格） |
| **拖动排版** | 长按图片拖动：拖进文字显示插入线，拖到图中间交换位置 |
| **标签** | 输入 `#标签 ` 加空格即成标签块；工具条 `#` 可选已有标签 |
| **公式** | 内置离线 KaTeX，`$$…$$`、`$…$`，直接写 `\dfrac{dy}{dx}` 也会排版 |
| **日记** | 按天归档，最近 14 天日期条，一天可以写多条 |
| **思维导图** | 每条笔记都能建画布，多条笔记也能连成一张大图，可导出 `.canvas` |
| **AI 问答** | 接 DeepSeek，多轮对话、可发图、回答可整条或选中一段写回笔记 |
| **轻量标记** | `**粗体**`、`- 列表`、`1. 列表` |

## 安装

### 方式一：网页 / PWA（最快）

```bash
git clone https://github.com/Yexingmaniqong/ruibu.git
cd ruibu
python -m http.server 8899     # 或 node sync-server.js 8899
```

浏览器打开 `http://127.0.0.1:8899`。
手机上打开 `http://<电脑局域网IP>:8899`，用浏览器菜单「添加到主屏幕」即可当 App 用。

> PWA 安装（离线缓存）需要 HTTPS 或 localhost。想给手机装 PWA，用隧穿工具把 8899 暴露成 https 地址即可。

### 方式二：Android APK

到 [Releases](https://github.com/Yexingmaniqong/ruibu/releases) 下载 `RUIBU-x.y.z.apk`，传到手机安装（需允许「未知来源」）。

APK 内部起了一个只监听 `127.0.0.1` 的极简服务，网页本体从 APK 自身的 `assets/` 读取，所以离线、本地存储、Service Worker 都正常，不依赖任何外部服务器。

### 方式三：Windows 桌面版

下载 `RUIBU-x.y.z-win64.zip`，解压后：

- 直接双击 `RUIBU.exe`，或
- 双击 `安装到本机.cmd` 装到 `%LOCALAPPDATA%\Programs\RUIBU` 并创建快捷方式

## 怎么用

### 写笔记

点底部「点击新建笔记」或右下角 `+`，进入**全屏编辑器**：

- 打字即可，最多只有一个"写点什么…"占位块
- 底部工具条四个按钮：`#` 标签、相册、拍照、`⋯` 更多
- 点空白处结束编辑并自动保存；点 `⋯` 可以加图、建画布、导出

### 标签

在文字里输入 `#高数` 再按**空格** → `#高数` 变成蓝色标签块，空格后面的内容仍是正文。
工具条的 `#` 按钮会列出**已建好的标签**供你选择。

### 图片

- **加图**：工具条相册 / 拍照，或把图片拖进窗口
- **单张成块**：多张图自动排成「一行四个」的网格，点右上角 ✕ 删除
- **塞进文字**：长按图片约 0.5 秒拿起，拖到某行文字中间，出现绿色竖线时松手
- **交换位置**：把一张图拖到另一张图的正中间，两张互换
- **插入到一起**：拖到两张图之间的缝隙（出现竖线），插到那里
- **看大图**：轻点图片

### 公式

行内 `$a^2+b^2=c^2$`，独立 `$$ \int_0^1 x^2 dx $$`，也可以直接写 `\dfrac{dy}{dx}`。

### 日记

侧栏「日记」→ 上方日期条选一天 → 「写日记」。笔记卡片右上角也会显示「日记」标记。

### 思维导图

- 笔记页的网格按钮（或「创建画布」）打开这条笔记的画布
- **先点一下画布**才开始操作（避免误触）
- 拖动节点移动，拖节点边缘的小圆点可以拉箭头连线，双指缩放，工具栏可适应屏幕
- 「关系画布」里可以把多条笔记拖进同一张图，导出为 Obsidian 的 `.canvas`

### AI 问答

1. 设置 → AI（DeepSeek）→ 填 API Key（`sk-…`，在 [platform.deepseek.com](https://platform.deepseek.com) 申请）→ 保存 → 测试连接
2. 侧栏「AI 问答」提问；输入框左边的图片按钮可以发图（取决于模型是否支持）
3. 回答下方可以「加到笔记」；选中一段文字再点，则只把选中的部分写进你指定的笔记
4. 对话会本地保存，换页面/重开都还在，可一键清空

### 备份与迁移

设置 → 数据：导出 JSON 备份、导入备份、导出 `.canvas`、导入 flomo 导出文件。
换设备时导出 JSON 再在另一台导入即可（没有云端同步是有意的取舍）。

## 数据与隐私

- 笔记、图片、画布都存在**本机 IndexedDB**；桌面版/安卓版另有自己的应用数据目录
- 没有账号系统、没有云端同步、没有遥测和统计
- API Key 只写入本机 `localStorage`，不进入笔记数据、不上传
- 仓库内不含任何用户数据（`sync-data.json` 已在 `.gitignore` 中）
- 唯一的对外请求：你自己配置 Key 后的 DeepSeek 问答

## 常见问题

**改了代码但界面没变？**
Service Worker 对 html/css/js 走网络优先，通常刷新即可；没变化就用设置页的「清除缓存并重新载入」。

**点「测试连接」提示失败？**
网页直连 `api.deepseek.com` 会被 CORS 拦，必须通过本机服务转发——用 `node sync-server.js 8899` 或 `start-sync.bat` 启动，而不是随便一个静态服务器。

**APK 装不上？**
先卸载旧版本；版本号递增（versionCode）才能覆盖安装。

**Windows 提示"未知发布者"？**
安装包未做代码签名，属正常现象。

## 开发

零构建链，改完刷新即可：

```
index.html          页面骨架 + 内联 SVG 图标
css/style.css       全部样式（三端自适应）
js/app.js           路由与视图：笔记流 / 日记 / 详情 / 编辑条 / AI 面板
js/canvas.js        自研无限画布（DOM 节点 + SVG 连线）
js/render.js        轻量富文本渲染（公式 / 粗体 / 标签 / 列表）
js/store.js         数据层：笔记 / 画布 / 图片压缩 / 导入导出
js/db.js            IndexedDB 封装
js/ai.js            DeepSeek 客户端
js/ui.js            弹层 / 确认框 / toast / 选择器
vendor/katex/       离线 KaTeX
sw.js               Service Worker
sync-server.js      零依赖本地服务：托管页面 + AI 代理
```
